# Bounded review of related work

Search date: 11 October 2026. This is a small purposeful sample, not an exhaustive literature review and not proof of uniqueness.

Queries included: Kenya election 2022 constituency turnout analysis registered voters data github; Kenya county budget dashboard analysis absorption public data 2024 International Budget Partnership; IEBC 2022 post election evaluation report; Parliament annual report 2023 2024 bills petitions sittings.

- [Paul-Oti, Kenya Election Data](https://github.com/Paul-Oti/kenya_election_data): repository README, licence, tree and election CSV inputs reviewed. Publishes reusable official-source transcriptions. Credited source for election CSV totals, not claimed as our original collection. MIT licence retained.
- [Samy Migwi voter dashboard](https://github.com/samy-migwi/kenya_2022_voters_dashboard_app): repository overview reviewed. Describes geographic vote contribution; not a code audit or comprehensive evaluation. No code or visuals copied.
- [ELOG election results](https://elog.or.ke/elections-results-home/): page reviewed. Provides election comparisons, county patterns and turnout framing. Its figures are not used as the source dataset here.
- [IBP Kenya County Budget Transparency Survey 2023](https://internationalbudget.org/publications/kenyas-county-budget-transparency-survey-2023/): publication overview reviewed, not its full dataset. Evaluates budget-information availability and comprehensiveness. Transparency is a different construct from spending absorption.
- [Parliament's comparison of the Houses](https://www.parliament.go.ke/the-senate/about-more-three): membership categories and functions reviewed for the structural explainer.

## Chosen contribution

A connected reading exercise across three public institutions: expose the denominator behind participation, the denominator behind spending, and the stage behind legislative activity. Show source limitations beside the interpretation and propose a testable reporting standard. This is a portfolio application of established analytical principles, not a new political theory or a comprehensive picture of Kenya.

Potential extensions need their own data and scope: bill-level status histories, verified project-completion records, audit findings, comparable election trends and public-information usability testing. These are not presented as completed analyses.
